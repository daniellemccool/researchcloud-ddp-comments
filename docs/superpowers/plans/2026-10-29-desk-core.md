# Desk Core Implementation Plan (plan 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the desk's own code so it is platform-definition driven, provisions a collector's session and 4CAT account on first visit from SRAM roles, enforces the 4CAT boundary in each user's proxy, and gives admins a daily surface without SSH, proven on the `checkjefeedzee` sandbox with TikTok.

**Architecture:** A stdlib-only Python package `desk/desklib/` holds every operation once (platform loading, capture rules, registry, rendering, 4CAT, provisioning, CO API, pool). Three thin CLIs (`desk-sessions`, `desk-template`, `desk-admin`) and the HTTP stub (`desk_stub.py`) call it, so the admin page and the operator commands run the same code. The mitmproxy addon imports only `capture_rules`, which is pure and tested without mitmproxy. Rendering of Compose and nginx moves from bash heredocs into `desklib/render.py`; the bash generator and its grep tests are deleted once the Python port passes the same checks.

**Tech Stack:** Python 3.12 (the box) / 3.14 (laptop), stdlib only on the box (`unittest`, `sqlite3`, `fcntl`, `urllib`, `http.server`, `zipfile`, `tarfile`); mitmproxy 12.2.3 addon API; Docker Compose v2; nginx `map`; Playwright for Python in a local `.venv` (uv) for the sandbox checks; Playwright browsers already cached in `~/.cache/ms-playwright`.

**Spec:** `docs/superpowers/specs/2026-10-28-src-catalog-item-design.md` (sections cited as §).

**Plans 2 and 3** (catalog item; Instagram) come after this one and are not written yet. This plan leaves hooks for them only where the spec names them: `desk.json` carries the parameters plan 2's Ansible will write; `provision.json` records `applied_generation` for plan 3's refresh; `login`/`keep_cookies` are loaded but only `release` templates are built here.

## Global Constraints

- Stdlib only for anything that runs on the box (no pip there). Python 3.12 syntax.
- Usernames: `^[a-z][a-z0-9._-]{0,31}$` (existing). Role names: `^src_co_[A-Za-z0-9_-]+$` (§5.2). Validate at every entry point that takes them; never interpolate an unvalidated value into nginx or shell.
- Registry cap default 99, ports `5800 + index`, index reuse for retired rows (§5.4). Running cap default `os.cpu_count() - 1` (§5.2).
- Locks: `<desk_root>/.render.lock` (global, registry allocation + render + reload only), `<desk_root>/locks/<user>` (per user, whole provisioning run) (§5.4).
- 4CAT boundary in the proxy (§6.1): allowed exactly `POST /api/import-dataset/` and `GET /api/check-query/` on host `fourcat.desk`; everything else on that host 403; hosts that are `localhost`, an IP literal, contain no dot, or end in `.desk` (other than `fourcat.desk`) refused 403; upstream `http://frontend:5000`, `Host: fourcat.desk`, client `Cookie` replaced by `remember_token=<token>`; redirects passed through, never followed.
- Safety-copy envelope (§5.5): `t, user, session, platform, capture, kind, post_id, request{method,host,path,query}, response{status,...}` plus `item` (items rules) or `body` (raw rules); `max_body_bytes` default 16 MB per rule; only `query_keep` keys from the query string are stored.
- Secrets: `secrets/4cat-passwords/<user>` root 0600; `secrets/4cat-tokens/<user>` uid 1000 0600 and bind-mounted only into that user's proxy (§5.4, §5.7). Never print them in logs or on any page except the admin's own password on request (§5.6).
- Every page string that names a person uses `desk_contact`; no hard-coded FQDN, path or name remains in `desk/` (§1).
- Sandbox: `ssh -F ~/.config/claude-ssh/config desk`; plain commands only (no `$( )`, no heredoc); scripts go over with `scp` and run by path. Never edit `/etc/nginx/app-location-conf.d/authentication.conf` or anything under `/etc/rsc/` (D11).
- Commits: conventional prefix with the component as scope (`feat(platform):`, `feat(capture):`, …), body ends with `Plan: docs/superpowers/plans/2026-10-29-desk-core.md` as the story anchor, then the Co-Authored-By line. Tests pass before every commit (`scripts/test-all.sh`).
